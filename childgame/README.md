# 小狐狸學堂

給臺灣大班（5–6 歲）的靜態小遊戲。小狐狸老師帶小朋友玩數字、注音、國字、英文和生活。

打開：<https://dl41o3su4-bit.github.io/childgame/>

## 數字

1. 數一數 `#count`（一顆一顆點，點完就過，不用猜數字）
2. 連連看 `#match`（大數字，點一樣多的那一群）
3. 下一個是誰 `#next`
4. 描一描 `#trace`（用手指描數字 1～10）
5. 誰比較多 `#more`（兩邊都點完才能比；點錯留下記號）
6. 第幾個 `#ord`（從左邊數，點那一隻）
7. 缺了誰 `#missing`
8. 湊一湊 `#bond`（把水果拖進空圓圈，點格子不算）
9. 畫線連連看 `#match-draw`（畫線把數字和一樣多的那一群連起來）

## 注音

1. 描注音 `#bpm-trace`（用手指描聲符 ㄅ～ㄙ）
2. 圖配注音 `#bpm-pic`（貼商標：廚房／公園／房間／餐桌裡，東西坐在冰箱、流理台、草地、架子上，詞已貼好；狐狸問「帽子的第一個音貼上去」；把聲符拖上去）
3. 注音連連看 `#bpm-draw`（每張圖都標詞，看字連到聲符）
4. 看圖認字 `#hanzi`（貼商標：圖坐在家具上，印的字就是那個字；狐狸問「哪個是山？把字貼上去」）
5. 聽音尋寶 `#bpm-listen`（聽詞找房間裡的東西：坐在桌子、流理台、草地、床、店窗上，再點第一個音）
6. 注音火車 `#bpm-train`（把圖拖上對的注音車廂，圖會坐上車）

## 英文

1. 描字母 `#abc-trace`（用手指描大寫 A～Z；狐狸說口訣）
2. 圖配字母 `#abc-pic`（貼商標：房間角落的東西上寫英文詞；狐狸問「Apple 的第一個字母貼上去」；X 用 Box）
3. 大小寫連連看 `#abc-case`（畫線把大寫和小寫連起來，會洗牌）
4. 字母連連看 `#abc-draw`（畫線把字母和圖＋詞連起來，會洗牌）
5. 字母泡泡 `#abc-pop`（聽字母，點破對的泡泡）
6. 字母小路 `#abc-path`（戶外石頭路，缺誰拖上去，狐狸走過去）

## 生活

1. 今天穿什麼 `#dress`（每題換人換地方：公園／海邊／山上／街頭；衣服貼在那個人身上）
2. 擺餐桌 `#table`（每題換吃飯地方：家裡圓桌／野餐／壽司店／早餐／夜市；餐具拖到少的人面前）
3. 誰住哪裡 `#habitat`（每題換風景：河邊樹林／海邊沙丘／山上草原／沙漠綠洲；動物待在對的地方）
4. 紅燈停 `#light`（每題換路口：市區斑馬線／學校門口／小巷；紅停、綠拖過去、黃等）
5. 分一分 `#sort`（房間／廚房／公園／洗澡前／超市／照顧動物，拖到對的家具）
6. 先做哪件 `#order`（起床→刷牙→出門等，拖到 1 2 3）
7. 身體在哪 `#body`（摸摸手、點點頭、跺跺腳、摸摸肚子；後面會先摸再摸）
8. 白天晚上 `#daynight`（上學日／週末／公園日，照一天的順序放）

答錯只說「再看一次」，同一題留下。過關加一顆星，存在 `localStorage` 的 `childgame-stars`。

本資料夾是完成的 HTML／CSS／JS／SVG，不必 npm 建置。相對路徑請用 `./app.js` 這種寫法，才能在 GitHub Pages 子路徑運作。
