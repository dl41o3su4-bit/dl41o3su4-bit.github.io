# 數字小探險

給臺灣大班（5–6 歲）的靜態小遊戲。小狐狸老師帶小朋友玩數字，也玩注音和國字。舊關新關都留著。

打開：<https://dl41o3su4-bit.github.io/childgame/>

## 數字（舊）

1. 數一數 `#count`
2. 連連看 `#match`（大數字，點一樣多的那一群）
3. 下一個是誰 `#next`
4. 描一描 `#trace`（用手指描數字 1～10）

## 數字（新）

1. 誰比較多 `#more`
2. 第幾個 `#ord`
3. 缺了誰 `#missing`
4. 湊一湊 `#bond`
5. 畫線連連看 `#match-draw`（畫線把數字和一樣多的那一群連起來）

## 注音國字

1. 描注音 `#bpm-trace`（用手指描聲符 ㄅ～ㄙ）
2. 圖配注音 `#bpm-pic`（圖下必寫大字；狐狸問「Ｘ的第一個音是誰？」；兩種唸法就刪）
3. 注音連連看 `#bpm-draw`（每張圖都標詞，看字連到聲符）
4. 看圖認字 `#hanzi`（圖＋印的字就是那個字，不轉一層；後面幾題也可畫線連）

答錯只說「再看一次」，同一題留下。過關加一顆星，存在 `localStorage` 的 `childgame-stars`。

本資料夾是完成的 HTML／CSS／JS／SVG，不必 npm 建置。相對路徑請用 `./app.js` 這種寫法，才能在 GitHub Pages 子路徑運作。
